# Leech minimal-vector classes as Element Data Object address space

## Question tested

This round tests the proposed use of all three shape families among the 196,560 minimal vectors of the Leech lattice. It separates two questions:

1. **Exact construction:** can Classes A, B, and C be generated with the claimed cardinalities and common norm?
2. **Chemical usefulness:** when typed elemental measurements are placed at fixed addresses from those classes, does the induced geometry recover held-out real-world element relationships better than the same measurements without that geometry or with random addresses?

The result supports the exact combinatorial construction. It does **not** show a special chemical advantage for any of the three address families in the current test.

## Data Object v3

`schemas/element_data_object_v3.json` extends v2 rather than replacing it. Every channel retains:

- its actual typed value and unit;
- explicit missingness;
- condition and uncertainty slots;
- provenance;
- one deterministic address in each of Classes A, B, and C.

The 24-bit Gray/Golay word remains the element identity/integrity layer. A Leech vector is an address for a channel, not an attempt to squeeze an arbitrary measured value into a finite code. This distinction is needed for losslessness and for chemically meaningful units and conditions.

Address IDs are reproducible SHA-256-derived indices with collision resolution. They were not selected from the outcome labels. The JSON schema records both IDs and resolved integer-coordinate vectors.

## Exact class construction

All coordinates below are integer-scale coordinates; divide by `sqrt(8)` in the standard Euclidean normalization.

### Class A

Enumerate every coordinate pair, then all four sign choices:

`(±4, ±4, 0^22)`.

Count: `choose(24,2) × 4 = 1104`.

### Class B

Generate all 4096 systematic extended binary Golay codewords, retain the 759 words of weight eight, and use each octad as the support of `(±2^8,0^16)`. Retaining the 128 even-parity sign masks gives:

`759 × 128 = 97152`.

### Class C

For each of 24 distinguished coordinates, start with `(-3,1^23)` and flip signs according to each of the 4096 Golay codewords:

`24 × 4096 = 98304`.

The all-one Golay word supplies the negative of the vector generated by the all-zero word, so both orientations are included without an extra factor of two.

### Audited invariants

`results/leech_class_audit.json` records:

- Golay weight distribution: `1, 759, 2576, 759, 1` at weights `0,8,12,16,24`;
- class counts: A `1104`, B `97152`, C `98304`;
- total: `196560`;
- no duplicates within a class and no overlap between classes;
- integer squared norm exactly `32` for every vector, hence normalized squared norm `4`.

The implementation tests all 196,560 generated vectors, not just representative samples. Lean additionally proves the count arithmetic and the norm calculation for representatives of all three shapes.

## Relationship experiment

### Inputs

Eight measured numeric channels from the existing PubChem snapshot:

- atomic mass;
- electronegativity;
- atomic radius;
- ionization energy;
- electron affinity;
- melting point;
- boiling point;
- density.

No outcome label is included as an input. Missing values are imputed with the training-fold mean and every field is standardized using only training elements.

### Geometry

For values `x_i` and assigned minimal-vector addresses `v_i`, the 24-dimensional representation is the superposition

`E(x) = Σ_i x_i v_i`.

Euclidean proximity in that representation is tested against two broad observed labels: same group/block category and same standard state. This is a representational consistency test, not a reaction or bond-energy model.

### Validation and controls

- leave one complete period out;
- preprocessing fitted on the remaining periods only;
- score only pairs wholly inside the held-out period;
- compare fixed A/B/C assignments with the raw standardized measurements;
- compare each family against 16 norm-matched random address assignments.

One period lacked both positive and negative pairs for a particular AUC calculation, so summary means contain six valid fold records. Full fold-level records are in `results/leech_class_relationships.csv`.

## Results

Mean held-out AUC:

| Representation | Same group/block | Same standard state |
|---|---:|---:|
| Raw measured channels | 0.8051 | 0.7485 |
| Fixed Class A | 0.7917 | 0.7438 |
| Fixed Class B | 0.7909 | 0.7485 |
| Fixed Class C | 0.7866 | 0.7419 |
| Class A random-address mean | 0.7901 | 0.7449 |
| Class B random-address mean | 0.7964 | 0.7522 |
| Class C random-address mean | 0.7927 | 0.7492 |

The fixed class geometries are close to their random-address controls and do not improve on the raw measured-channel baseline. Class B nearly matches the raw baseline for standard state, but its random controls do slightly better on average; this is not evidence for a privileged B assignment. Standard state is also a weak independence test because melting and boiling points are direct physical determinants of phase under specified conditions.

## What is valid, and what is not yet supported

**Validated exactly:**

- the supplied `1104 + 97152 + 98304 = 196560` inventory;
- the Golay dependence of B and C;
- common minimal norm for all generated vectors;
- deterministic, lossless attachment of all current element channels to all three address families.

**Not supported by this experiment:**

- a claim that one Leech class is intrinsically aligned with periodic chemistry;
- extra held-out signal from these fixed addresses;
- a Monster-group causal model of elemental behavior;
- prediction of interactions, compounds, or reactions.

The Monster/Leech relationship motivates mathematically coherent symmetries and address spaces, but that fact alone does not make a chemical mapping unique. A mapping can only become an empirical model after its semantic rule is fixed before outcome testing and it beats ordinary and randomized controls.

## Best next test

The next dataset should contain genuine interaction observations, not labels derived from isolated elements. Recommended first endpoint: gas-phase diatomic dissociation energy with species identity, charge, electronic state, temperature/measurement conditions, uncertainty, and provenance. Build a pair/event object with:

1. two v3 element subjects;
2. an explicit ordered or symmetric pose rule;
3. stoichiometry and electronic state;
4. a measured endpoint;
5. complete-element holdout, so no pair containing a held-out element appears in training.

Pre-register a small number of A/B/C interaction operators (for example inner products, sums/differences, and Golay-support overlaps), then compare them with atomic-number, standard chemical-descriptor, raw-channel, random-address, and shuffled-target controls. This directly tests whether the larger Leech space contributes reusable interaction signal rather than merely providing many possible arrangements to search.
