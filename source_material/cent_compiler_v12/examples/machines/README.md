# Computational machine bundles

Generated by the experimental `cent machine` side-arm. A machine bundle is a
complete staged concept, not a fabricated device or a measured circuit.

| Machine | Concept | Bundle |
|---|---|---|
| `sigma-delta-sqrt` | one-bit ∆Σ carrier for √2, with input conditioning, digital decimation and an explicit unmodeled analog branch | [`sigma-delta-sqrt/machine.md`](sigma-delta-sqrt/machine.md) |

Each bundle contains:

- `machine.json` — the portable `cent-machine/1` payload;
- `machine.md` — the whole function tree, selected parts and evidence;
- `machine.cir` — the behavioral electrical delta-sigma core only.

Regenerate with:

```bash
python3 cent machine sigma-delta-sqrt --out examples/machines/sigma-delta-sqrt
```
