# D6 retrodictive holdout

`ledger.json` is generated by:

```bash
python3 cent holdout --write examples/holdout/ledger.json
```

It is a `cent-retrodictive-holdout/1` with a five-mechanism library frozen at
knowledge available before **1940**, and five targets first published after
that cutoff.

| Target (post-cutoff) | Source (pre-cutoff) | Target year |
|---|---|---:|
| simulated annealing | metallurgical annealing | 1983 |
| resistor networks | random walks | 1984 |
| Hopfield associative memory | Ising spin model | 1982 |
| lattice Boltzmann | kinetic theory | 1988 |
| Steiner-tree computation | soap-film minimal surfaces | 1941 |

The measured positive result is **5/5 rank-one recall, zero positive-case
misses**. One candidate is a declared false positive: `kinetic-theory` is
retrieved for the exact-rational resistor-network target but carries
statistical precision. That candidate is retained in the ledger rather than
filtered out. Other unexpected candidates remain in the triage queue, because
an unlabelled candidate is not a false positive.

## Negative control

The ledger also contains one pre-registered strict control: RSA modular
exponentiation (1978), whose defining `mod` primitive is absent from every
frozen source. The machine returns `outcome: no_licensed_source`, retrieves no
candidates, and records a coverage miss. This is a deliberate failure record,
not a positive recall case: it shows that the matcher does not fall back to
structural ranking when the strict operator requirement is absent. The known
number-theory source is outside this curated library.

The **Bresenham ↔ delta-sigma** candidate is excluded. Bresenham's algorithm was
published in 1965, so it cannot be a source in a 1940 frozen library; the D4
one-tick correspondence is internal evidence, not a dated external transfer.

## Direction and provenance

The directive's arrows are conceptual shorthand, not temporal order. A case
always names the post-cutoff publication as the target and the pre-cutoff
principle as the source. Two directive shorthands are therefore recorded in
their historically dated direction:

- Hopfield associative memory (1982) ← Ising spins (1925);
- Steiner-tree computation (1941) ← soap-film physics (1873).

Each case carries a publication citation and a provenance URL. The target
signatures are declared from the published problem statement, not read from a
mechanism card's `supported_operations`. The resistor-network case cites the
1984 Doyle & Snell monograph; Kakutani's 1945 connection is earlier and is
acknowledged, so the ledger does not claim the first-ever statement of that
relation.

## Limits

The frozen library is a separate hand-declared holdout library; it is **not** a
snapshot of the live mechanism registry. The target signatures are also
hand-declared, and five cases are a regression test rather than general
evidence of retrodictive power. Two targets (simulated annealing and
Hopfield associative memory) share a signature with their source, so those cases test
provenance recall more than structural re-description. The ledger records these
gaps explicitly and does not claim a proof of the historical analogy.
