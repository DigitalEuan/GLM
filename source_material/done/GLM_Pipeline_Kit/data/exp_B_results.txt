================================================================================================
EXPERIMENT B (Notes 1-2) -- Trace supervision vs. final-answer-only
================================================================================================

Tiny binary recurrent GLM (T=2, linear recurrence, sigmoid readout):
  z_D = A(D)       -- task encoder = y1 XOR x1 (the F_2 displacement)
  b_0 = E(x_q)    -- binary encoder (query flattened into first 24 of 32 cells)
  b_t+1 = F_θ(b_t, z_D) = W_t b_t + U_t z + c_t  (linear, per-step)
  r_t = sigmoid(R b_t + d)  (shared readout)

Training:
  FINAL_ONLY : minimize BCE(r_{T-1}, y) only.
  TRACE      : minimize Σ_t BCE(r_t, u_t) at every step (λ_trace = 1.0).
  Same architecture, same data, same optimizer; only the loss differs.

3 seeds, 500 train / 100 val per seed, 60 epochs, 4x6 grids, lr=0.5.
