run the substrate's exact_real.golay_delta_sigma for 400 ticks. The
trajectory visits codewords; the accumulator tracks target error.

Interpretation:
  * 'unique cw' = number of distinct codewords the wobble visits.
    High -> orbit is diverse; the target is far from any codeword.
    Low  -> orbit concentrates on a few codewords (target IS close to a
            codeword, or the substrate has a periodic attractor there).
  * 'most share' = the fraction of ticks spent at the most-visited codeword.
    1.0 = stuck at a single codeword (target IS a codeword).
  * 'max dev' = the worst coordinate-wise deviation of the running average
    from the target. If within 1/400 = 0.0025, the 1/N bound holds.
  * 'hull sep' = True iff the target lies OUTSIDE the convex hull of the
    4,096 codewords. Such targets are PROVABLY UNREACHABLE by any
    quantiser rule — the substrate must escalate to a higher lattice.
