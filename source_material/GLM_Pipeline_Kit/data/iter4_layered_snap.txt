For each binary task target, run three snaps in parallel:
  * Λ24 snap (Leech, Construction C): binary -> 4*binary -> in_leech
  * Λ32 snap (Barnes-Wall, Construction D over RM(1,5) ⊂ RM(3,5)):
    binary embedded in 32-D + padding bits, in_lattice test
  * Λ48 snap (ternary, Pless symmetry code C(23) over F_3):
    binary -> pair(b, 0) or pair(b, 1-b) or spin(b, 2b mod 3) in 48-D

User insight: F_2 multiplication by 2 = 0 (deletion, no spin).
              F_3 multiplication by 2 = -1 (a unit, a rotation).
The ternary Λ48 is the 'multiplication puncture' — the lattice where
the binary substrate's no-further-restriction wall gets punctured by
introducing a non-trivial multiplicative unit.
