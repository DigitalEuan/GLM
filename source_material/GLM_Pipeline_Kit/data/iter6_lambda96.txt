Interpretation:
  * Λ_96's trivial 3x embedding works for ALL binary targets (100% snap rate).
    This is the multiplication puncture in action — the 3x scaling makes
    every target mod 3 = 0 (the zero codeword), which is trivially in C_96.
  * The spin test measures how many distinct 'orientations' the snapped
    target admits within Λ_96. Three spin operations are tested:
      (a) mult by 2 (F_3's unit, a swap 1↔2): always works for 3x embedding
          because 3*b mod 3 = 0 and 2*0 = 0 still.
      (b) pair swap (F_9's α operation in the lifted basis): swaps coords
          (0,1), (2,3), ..., (94,95). Tests whether the F_9 spin structure
          is captured by the F_3 lift.
      (c) coord invert (1→2, 2→1): a different F_3 spin operation.
  * The 'spin superposition count' = how many of these orientations are
    valid Λ_96 points. Higher count = more superpositions held by the GLM
    before clarification. This is the user's 'superposition' intuition made
    operational at the lattice level.
