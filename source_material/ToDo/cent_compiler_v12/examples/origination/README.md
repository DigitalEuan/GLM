# D8 origination ledger

`cent originate --write examples/origination/ledger.json` writes this
`cent-origination-ledger/1` artifact. The search composes the
`kcl-conservation` principle with each of the seven declared TIER-3
analogies; it accepts only power-conjugate effort/flow pairs and refuses the
rest with recorded reasons. The three originated pairings (acoustic,
rotational, electromechanical) pass an independent exact oracle; the fluid
record is re-derived from the W1-W6 analogy as derivation parity. The
scoreboard's origination rate moves from `1/9` to `4/9`, meeting the `>=3`
target without inventing any non-declared analogy.
