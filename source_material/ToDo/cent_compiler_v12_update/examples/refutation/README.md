# Tier-D generated negatives

`negatives.json` is generated by:

```bash
python3 cent refute --write examples/refutation/negatives.json
```

It is a `cent-tier-d-ledger/1` with 13 declared instances and **8 generated
negatives**, compared with the **6 hand-declared** negative controls in
`cent_compiler/transfer_evaluation.py`.

Each generated negative is a `cent-tier-d-witness/1`:

- the two instances share the complete listed signature;
- their required observable differs on a named probe;
- therefore no map through that signature alone exists.

The Q-tensor pair reproduces the recorded retirement of
`nematic-q-tensor-bounding-box`: identical scalar invariants
(`S=1`, `tr(Q^2)=2/1`, `det(Q)=-1/1`) but envelope areas `2/1` and `66/25`.
The carry pair preserves the D4 timing witness (`1,1,1,0,0,0` versus
`0,1,0,1,0,1`). Junction carriers, log-domain operations and exact arithmetic
laws supply the other separations.

The ledger also contains ten derived test obligations, all with
`authored: false`:

- `quantized_carry` bounded-state and mean-reconstruction, derived from the
  operation contract's `code` and `mean` output declarations;
- one observable-separation assertion per witness.

This is a refutation of a signature-only map, not a claim that no richer map or
physical transfer can exist. `cent refute` and `review/refuter_demo.py` emit the
same ledger.
